BB-BIO-001 - Bioseguridad, vestimenta y elementos de protección personal (EPP)

Código BB-BIO-001 Versión 0.1

Aplicación Ambas unidades Elaborado por Dr. Martín Ledesma
Aprobación Coordinadora CEMET Viviana Fanessi Revisión Anual o ante cambio regulatorio
Documentación Registro electrónico y/o formulario controlado Sistema NORAYBANKS + registros institucionales

Propósito

Establecer requisitos mínimos de vestimenta y de EPP para el trabajo seguro con muestras biológicas y equipos de ultrabaja temperatura.

Alcance

  • Todas las actividades dentro de las salas y zonas de manipulación.

Responsabilidades

  • Todo el personal: cumplimiento obligatorio.

  • Técnico: verifica la disponibilidad de EPP y su cumplimiento.

  • Director: evalúa desvíos reiterados.

Definiciones / criterios

  • Guardapolvo cerrado, pantalón largo y calzado cerrado son obligatorios.

  • Guantes descartables durante la manipulación de muestras; protección ocular y facial cuando exista riesgo de salpicaduras o roturas.

  • Para -150 °C, se utilizará EPP criogénico apropiado según la tarea y el fabricante.

  • Prohibido comer, beber, fumar, almacenar alimentos o usar el teléfono personal con guantes contaminados.

Procedimiento

1. Colocar guardapolvo antes de ingresar al área operativa.

2. Realizar la higiene de manos antes y después de usar guantes.

3. Cambiar guantes si están dañados o contaminados, o al cambiar de tarea cuando exista riesgo de contaminación cruzada.

4. No tocar picaportes, teclados o teléfonos con guantes utilizados para muestras; retirar o cambiar los guantes antes de hacerlo.

5. Ante un derrame, aplicar BB-BIO-003.

Registros obligatorios

  • Checklist de apertura de sala.

  • Registro de capacitación de bioseguridad.

  • Registro de incidentes/exposición.

Indicadores y control

  • Cumplimiento observado de EPP.

  • Incidentes de exposición o derrame.
